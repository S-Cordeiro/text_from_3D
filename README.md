# Text from 3D

This projects starts from an idea (which is not entirely new) to start from multiple views of a blender generated scene, and to train a neural network to give a description of this scene, or at least to identify what objects are present (what are their position, rotation, etc...)

This is just the beginning of the project, and for the moment, the objective is to identify the position, scale and rotation of multiple cubes in the scene from 8 views. The architecture is inspired from DETR.
