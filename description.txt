Voici un document ou je décris le projet text_from_3D.

Objectif : 
    Entrée : plusieurs vues (entre 2 et 6) d'une même scène générée en 3D avec blender.
        L'avantage de blender, c'est qu'on peut créer facilement un dataset synthétique.
        Les scènes seront au début très simples : des cubes ou des sphères, voir si on peut complexifier ensuite.
    Sortie : un texte de description de la scène (pose des caméras, position des objets)
        Ce texte sera généré par un LLM avec des tokens spécialement conçus pour l'occasion
            (pour limiter le nombre de tokens et faciliter l'entrainement)
        Les coordonnées des objets devront être exprimées dans le référentiel de la première caméra.
        Une des difficultés est que les objets pourront être dans des ordres arbitraires. Pour cela :
            - soit donner une couleur aux objets, qui matérialise l'ordre dans lequel il faut les énumérer.
            - soit faire une permutation, celle qui correspond le mieux à la scène.

L'avantage de ce projet est qu'on peut le simplifier tout comme on peut le complexifier.
Il touche à la vision, et aux LLM.
Il est entrainable end-to-end avec les ressources dont je dipose (j'espère).

Plusieurs grands axes qui seront à développer :
- Génération des données : images et description
    - idéalement pas trop couteux à changer si on se rend compte qu'il faut les modifier.
- Choix du tokenizer : 
    - Le moins de tokens possible pour faciliter l'entrainement
    - tokens de chiffres et tokens d'instances, token de fin
    - Choix de l'architecture globale : partie vision, partie LLM, le lien entre les deux
        (enfin a priori ça va, le LLM va juste prendre les tokens du VIT)
    - Entrainement, optimisation
